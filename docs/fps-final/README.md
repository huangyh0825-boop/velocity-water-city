# 保留画质的帧率优化与发布验收

2026-10-19。以刚完成 AI 配速调整的本地版本为对照。本轮保留模型、贴图、水面波纹、实时反射、阴影和驾驶规则，并包含此前的加载优化、捷径空气墙、水面长实线与护岸接缝修复。

## 实测结果

同一 Edge 进程，修改前 / 修改后 / 修改后 / 修改前顺序；RTX 4060 Laptop，1600×1000、DPR 1、标准画质。每段预热 60 帧，再记录 240 次实际行驶绘制。AI 分散场景中四艘 AI 仍正常运行，只是没有人为集中放在玩家身边。测量时不运行其他测试。下表合并两轮帧时间后换算 FPS。

| 场景 | 修改前 FPS | 修改后 FPS | 平均帧率变化 | P95 帧时间 |
| --- | ---: | ---: | ---: | --- |
| 城市路段，AI 分散行驶 | 53.30 | 60.18 | +12.90% | 23.30 → 21.05 ms |
| 城市路段，五艇密集 | 37.99 | 38.21 | +0.57% | 31.45 → 29.30 ms |
| S2 高架，五艇密集 | 36.34 | 36.42 | +0.22% | 35.10 → 33.45 ms |

城市分散行驶的收益明显；五艇同时近景显示仍受高精度几何绘制限制，平均帧率基本持平，较慢帧有所改善。不能把 12.9% 套用到所有路段、设备或分辨率，也没有承诺全程 60 FPS。CPU 提交耗时分别为 18.24 → 16.09、25.02 → 20.93、26.63 → 24.16 ms/帧；它包含同步等待，不能单独等同于 GPU 耗时。

每组对照的实际行驶终点、检查点状态、绘制调用和三角面数一致。[完整性能记录](performance.json)。

## 保留的改动

- 岸边设施先执行原有精确视锥检查，再对镜头内的实例计算原有细节等级；主视角、反射和太阳阴影分别保留独立结果，实例顺序不变。
- 将屏幕与反射通道的 PBR 材质程序状态分开缓存，减少在两种输出空间之间反复生成程序参数。共享原纹理、颜色/向量引用和着色器钩子，同步实时数值；材质重载、释放时同时清理缓存。水面、粒子及深度材质保持原路径。

没有减少模型面数、贴图分辨率、场景物体或水面尾浪样本，没有降低阴影/反射分辨率或更新频率。没有调整玩家速度、转向、物理步长、碰撞、跳台、特技、氮气和 AI 配速。空间网格/分层遍历试验在本地图反而更慢，未保留；水面包围范围试验收益很小，也未保留。

## 画面对照

市区近景、远景、高架、隧道、S2、反向镜头共六组。每组可见实例及顺序、反射实例、离屏太阳阴影投射对象、绘制调用和三角面数逐项相同。标准水面细分 320、反射贴图宽度 1024、五艘艇局部阴影均为 2048；原贴图与完整模型保留。

1280×800 的六组 PNG 对照，RGB 平均绝对误差最大 0.006514/255；差异像素最多 624 个，占 0.06094%，单通道最大差值 49。存在少量像素差异，没有宣称逐像素完全一致。[实例及规格摘要](visual-state.json)、[像素差异记录](visual-diff.json)、[原始截图](visual/after-city.png)。

## 功能验证

- 170 项自动化测试、TypeScript 检查和最终生产构建通过。
- 默认与拥挤发车的 AI 三圈测试通过。实际 Game.frame 浏览器复测中，四艘 AI 均通过 72 次合法检查点：最快 4:29.97–4:29.98，第二艘 5:03.22–5:03.65，第三艘 5:25.38–5:26.87，最慢 5:41.10–5:41.75。
- 两条捷径的主路/捷径四条完整路径及 24 组低速改道、折返通过；合法水面没有误触边界或位置纠正。
- 生产页面的电脑键盘与手机触屏、重开倒计时、加载失败重试，以及无私有 QA 入口、无脚本错误/404 检查通过。

三圈功能测试为提高验证效率跳过 GPU 绘制，并恢复画面截图，不能当作帧率。上面的 FPS 测量始终保留完整渲染。

线上冷启动复查还发现：资源仍在持续下载时，原先固定两分钟的截止时间会提前失败。现按流式接收的数据及已完成资源重置“无进展”计时，仍保留两分钟无进展报错、十分钟整体上限和失败重试；没有减少下载内容或降低画质。新增回归模拟超过两分钟但持续有数据，以及连接停滞两种情况，并核对流式读取的每个字节。此改动只影响启动等待，不进入逐帧驾驶或渲染计算。
