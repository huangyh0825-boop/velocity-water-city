# 捷径贴墙修复与首次玩法教程

## 行为

- 在捷径分流处，旧路线标签可能还指向另一条水道。船体贴墙、两条水道都无法完全容纳当前船体朝向时，旧逻辑坚持按旧路线纠正，造成跨隔墙拉回。
- 保留普通擦墙的原有处理。当旧路线所需纠正超过最大船体边距 2.6 米，允许选择同高度、纠正更小的水道。仍有实体边界、高度判断和完整碰撞；显式规划路线的 AI 保留原有处理。
- 客户端和 Node 服务器复用 `CityTrack`，两端必须同时部署。
- 键盘教学明确显示“左Shift”。首页有“玩法教程”，新玩家保存 ID 后、已有玩家首次访问新版首页时自动显示一次；之后可重看。教程只在首页出现，不干扰多人加载及倒计时。
- 四幅 SVG 图解释跳台、空格特技、安全落水获得 35% 氮气、按住左Shift加速；包含手机操作说明。无需新增图片下载、3D 资源或每帧更新。

## 验证

- 228 项 Node 测试和 13 项真实 Workers 回归测试通过；前端、Node、Workers 与 Workers 测试的 TypeScript 检查通过，生产构建通过。
- 新增贴墙几何回归覆盖两条捷径、两侧岸边、正向/横向/反向、过期路线标签、碰撞推出水道边缘，以及实际 `RoomRace` 的权威碰撞纠正。
- 原有 AI 圈速、完整三圈、捷径检查点、驾驶及多人碰撞回归通过。
- `scripts/qa/tutorial-browser.mjs`：1440×900、390×844、844×390，首次 ID、已有档案、刷新记忆、Esc、首页重看、进入训练和左Shift文字均通过，无横向溢出或页面异常。
- `scripts/qa/online-race.mjs`：两个独立浏览器，全员准备、故意延迟一人加载、统一五秒倒计时、实际驾驶、掉线恢复、一分钟通信及返回首页通过。
- `QA_SHORTCUT=1 node --import tsx scripts/qa/online-contact-browser.mjs`：私有测试入口，真实 3D 双客户端，单向 100ms 网络延迟；在第二捷径岸边以过期主路线标签开始，擦墙加速后两人均留在所选捷径，跨视角颜色一致。测试夹具只修改测试进程，不进入生产入口。

## 性能边界

未修改模型、材质、水面、阴影、分辨率、画质默认值、AI 参数或驾驶参数。正常水道的快速路径保持原样；同进程 ABBA 微基准中，每 20,000 次正常边界检查在修改前后都恰好查询 20,000 次投影。教程没有游戏内每帧工作。该微基准不能当作真实设备 FPS 测量或 FPS 提升声明。

浏览器验收记录和截图保存在本机忽略目录 `work/shortcut-tutorial`、`work/shortcut-online`、`work/shortcut-contact`。正式发布后另核验 Render 修订、Pages 工作流成功和公开脚本完整 SHA256。
