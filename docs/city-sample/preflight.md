# 城市样板区：修改前检查

2026-10-14。基线提交 edd56d0，标签 city-art-baseline，工作区原先干净。本次仅升级主线进度约 3.05%–8.95%（280 米）的中央水道视觉。

1. **几何**：CityDistricts 的主体仍是 Box/Cylinder/Lathe 基础体，桥体只有梁和少量支撑，没有完整桥面边缘、连接构造和栏杆。已有 GLB 加载仅用于艇/角色。
2. **材质**：glassFacade 是 64×128 色块纹理；没有立面凹凸、面板粗糙度、UV 比例和接缝细节。金属/混凝土为单色 PBR 参数。
3. **光照**：已有晴天日光、2.8 强度半球光、PMREM 环境反射。未开启建筑投影，底座与立面缺少遮挡层次；强环境光削弱形体对比。
4. **细节**：岸边只有连续平面，缺少构造接缝、栏杆、护舷、码头设施和近景尺度参照；广告数量不是主要缺陷。
5. **重复**：每区反复生成固定模板，随机尺寸仍难构成有辨识度的街区。

计划使用免费合法 PBR 贴图，若没有足够合适且可直接获取的建筑模型，则用官方 Blender 便携版制作三种可复用建筑、完整桥体及曲线岸壁。模型纯视觉，绝不更改赛道/检查点/AI/船体。

旧图保留相同相机参数，后续对比不移动镜头或改变视野来夸大效果。摩托、驾驶员、水面物理和竞速保持基线。
