# 280米城市样板区验收

2026-10-14。基线 edd56d0 / `city-art-baseline`。本次没有更改路线、检查点、船体、角色、驾驶参数、AI、跳台、特技、氮气、比赛和碰撞代码。Game 仅增加视觉加载、质量切换、静态影子与资源释放；CityDistricts 将样板内旧楼宇分组，成功加载后隐藏，失败保留旧模型。

## 美术实质变化

旧版的阶梯方柱、平面岸台和粗粒度幕墙，替换为三种可复用的 Blender 原创模块：渐缩弯曲 Aster 塔、扭转双翼 Helix 塔、开孔退台 Marina 展馆。模型包含真实窗框/楼板、曲面轮廓、楼宇底座、连廊、屋顶设备、阳台及中庭，不是仅在旧基础体上增加灯带。

完整 Lumen 桥包含倒角桥面、曲线压拱、吊杆、完整栏杆、桥墩与基础、支座环、导航灯。曲线岸壁严格沿现有采样生成，增加压顶、护栏、护舷、系缆桩、灯具和码头；连续地台填补原楼宇悬浮感。近中远三个层次由双翼塔、展馆与高塔构成，范围外旧城市保持。

制作方法：Blender Python 操作截面网格、挤出、曲线、倒角、加权法线、屋顶中庭布尔开孔、UV与PBR。源文件保留可复用集合实例、曲线与修改器，屋顶布尔结果已烘焙为可编辑网格。运行导出复制源对象并按材质合并，不覆盖源模型。源码、源文件及贴图详见 [资产说明](../../assets/city-sample/README.md) 和 [素材清单](resources.md)。

阴影：标准画质使用局部2048² PCF日光阴影图，建筑/地台接收；水面用轻量透明接收面近似，不是实时水面反射。静态街区只在加载/质量改变时刷新阴影图。原半球光强度和水面着色器未重新设计，因此整体光影仍偏平。

## 测试

- 76/76 自动化测试通过（原75项保留）；新增GLB结构/贴图、真实LOD面数、路径参考一致性及艇可用水道净空检查。
- TypeScript `tsc --noEmit` 与 Vite 生产构建通过。Three.js块553.98KB仍触发Vite大于500KB提示，未隐瞒/屏蔽。
- 净空测试：标准与低精度模型全部读取真实位置/节点变换；12米以下可见实体顶点没有伸入有效水道。开发检查确实发现了两个标牌基座侵入，已按原岸线修正后重新导出并通过。桥底18.6米，桥墩外置；新结构没有加入物理障碍。
- 浏览器实际Game自动输入三圈：首圈不用氮气109.23秒，总319.53秒，72门、9次跳跃/落地、9次特技奖励，氮气峰值216km/h；AI起跳6/6/3/5、奖励5/6/2/3，重新开始清除结果和计时，无浏览器异常。使用虚拟时钟，不能据此宣称全程真实性能。
- 原实体AI拥挤起跑与三圈、碰撞位置修正起跳等自动化回归仍通过；此浏览器理想路线没有自然接触，不将其冒称人工碰撞试玩。
- 生产127.0.0.1:5174：新标准GLB HTTP200，W真实键盘加速到91km/h、A转向、S制动至零、重赛恢复40%能量；生产无测试Game全局入口。
- PC浏览器街区键盘运行加速到110km/h；GLB/广告正常加载、低质量切换成功，阴影及透明接收面关闭，没有console/page异常。
- 本机同视角5秒短时**渲染**对比：Edge无头1440×900，RTX4060 Laptop；旧/新均约240FPS，P95约4.3/4.2ms，主渲染调用46→48、三角面132,697→387,857。测试期间暂停模拟以保证同位置，因此这是渲染负担比较，不能等同全赛程或其他电脑保证60FPS。
- 触控横屏模拟入口：默认低画质，只请求低精度街区GLB而不先下载标准11MB文件；按钮可见、资源HTTP200、没有浏览器异常。没有真实Android/iOS实机验收。

## 限制和等待验收事项

**尚未达到《激流快艇2》成品美术水平。** 本版已改善曲面结构、立面、桥梁与水岸，但材质仍缺少专业烘焙的立面AO/高质量玻璃环境内容、细致旧化和色彩分层；日光/环境光比仍偏平。没有镜面水上建筑实时倒影，也没有新增绿化/人流等成熟场景叙事细节。楼宇重复两次是模块复用，并非整座城市已完成。

标准资源新增约11MB，低质量约3.46MB，未做网格压缩；初次联网加载成本增加。虽本机短样本流畅，低配设备和长时间性能、GC及真实手机尚需验证。阴影接收水面是平面近似，与小波动不同步；广告和栏杆背面仍可在非行驶观察角度看出简化。

请重点确认：发车后约150–430米街区、三种建筑的造型/尺度、桥梁完整度、从驾驶镜头能否看出精度提升，以及是否接受当前玻璃和光照风格。本次不扩展至全地图，不修改艇/角色，不部署GitHub Pages。等待美术确认后再决定下一步。
