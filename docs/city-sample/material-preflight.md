# 质感强化：改动前诊断

基线：city-material-baseline / 8821512。样板仍为280米，赛道和游戏状态不变。

1. **桥梁（最明显）**：拱梁、桥面、建筑肋条大量共用Pearl ceramic单色材质（金属度0.25、粗糙度0.32）；既不像裸金属，也没有涂层微表面。圆管式拱、缺少拼接/吊杆连接、桥墩过渡简单，增加玩具感。
2. **高楼**：已有实物窗框与法线/粗糙度，但蓝/银玻璃参数在Blender和加载时分别设定，运行又覆盖金属度。幕墙闭合截面的UV在最后一个面从近2跨回0，造成不合理纹理跨度；低分辨率单点反射强调大块明暗轮廓。基座与屋顶没有够细的面板分区/AO。
3. **护栏/设施**：已使用真实CC0金属Normal/Roughness，但曲线杆件表面尺度一致、缺少连接套和锚固点。0.08m阴影normalBias大于细杆半径，使小接触点难落影。
4. **平台/外墙**：多数单色，粗糙度常量；通用UV以X/高度投影，对法线沿X的立面会压缩U方向，无法正常展示PBR细节。基座距地约5cm，接触阴影弱。
5. **路牌**：已修复41块牌的双面方向；显示屏材质主要表现为发光平面，缺少靠后的密封背板和屏框。文字UV不应重新改变。
6. **光照/表面层次**：半球光1.8、日光3，间接填充仍较强；无AO图、结构凹槽只依赖较大范围静态阴影。近景和远景使用相近表面处理，缺少尺度差异。

优先顺序：修正UV/边缘法线 → 原创涂层/混凝土面板PBR与局部AO → 工程桥拱/连接件 → 基座/框架接触层次 → 光照比例/反射 → 同镜头与驾驶验收。AO会明确区分程序化接缝近似、接触贴片与真实烘焙；不把它们宣称为高精度光线追踪AO。

后续导出内容核验还确认：旧玻璃Normal/Roughness两张图哈希相同且均为黑图，写像素后再切换Non-Color清掉了缓冲。已修正为先设置色彩空间再写像素，并直接测试GLB像素内容，防止只有贴图文件名而没有实际细节。
