# Phase 3 功能与验收

在现有项目中增量实现跳台、空中特技、氮气、水花和合成音效。没有替换项目、赛道逻辑或比赛系统，也没有新增外部物理/音频依赖。

## 已完成功能

- 原水道中设置 3 处绿色边缘跳台，位于路线角度 0.38、2.00、4.36 弧度。宽 10 米、长 12 米、高 2 米；从船身安全宽度内正向驶过坡面与台沿后腾空。跳台宽度留有可绕行空间。
- 独立纵向弹道，重力 14 m/s²，起跳纵向速度为 4 + 0.14 × 进入速度（m/s），进入速度至少 2 m/s。水平驾驶与转向仍由原模型控制；赛道边界持续约束水平位置，落地归零并保留前进状态。检查点拱门提高净空，不改变其水平位置与判定。
- 空格触发一次自动特技。充足空中时间下依次选择前空翻、后空翻和水平旋转；剩余时间不足时优先使用较短的水平旋转。单次腾空只能接受一次操作；只有动作完成且安全落地，才获得 35% 氮气。晚触发或不安全落地减少当前速度 28%，随后按原驾驶模型恢复。
- 特技仅旋转船身的视觉子组，实际位置、航向、水平胶囊体和排名不受特技旋转干扰。碰撞增加高度分离判断，飞过水面船只时不错误地拉回，低高度接触与落地仍参与碰撞。
- 按住 Shift 使用氮气，松开或耗尽停止消耗。每赛初始 40%，每秒消耗 22%，上限 100%；奖励不跨比赛累积。正常上限保持 180 km/h，氮气上限 216 km/h（+20%），附加加速度 6 m/s²。释放后超出正常上限的速度按 8 m/s² 平滑回落。
- 氮气增加短促蓝色喷射，镜头额外拉远 1.4 米、FOV 增加 4°。非氮气、非腾空状态仍使用原镜头参数，未加入动态模糊。
- 尾浪随速度增加频率并快速淡出；腾空和上坡离水后停止贴水尾浪。独立水花池支持高速、转弯、起跳、落水和接触反馈。PC 池容量 360，低画质 96，降低发射率和绘制范围。所有粒子复用；同一对船的碰撞反馈至少间隔 0.25 秒。
- Web Audio 原创合成发动机、水流、高速破浪、氮气启动/持续、离水、落水与碰撞声音。频率和增益平滑变化；首次用户键盘或触摸交互后初始化/恢复。固定 3 个持续声音源，同时最多 6 个短音效。总音量与开关独立于比赛重置，后台静音，生命周期结束关闭音频上下文。
- 手机保留原转向、加速和刹车，并新增特技、氮气触控入口；本阶段只验证基础横屏兼容。

## 验证结果

- 按跳台 → 特技/奖励 → 氮气/HUD → 水花 → 音频的顺序开发，每步完成后执行自动化测试和生产构建。
- 最终 `npm test`：41/41 通过。原 29 项回归保持通过；新增覆盖方向性跳台、速度相关飞行、三种动作、失败惩罚、奖励限次、能量上限/耗尽/重置、216 km/h 及平滑释放、粒子预算与消散、速度/转弯发射变化、反馈限频、空中/落地碰撞、氮气高速防穿透、跳跃和氮气后完整三圈比赛。
- `npm run build`：TypeScript 检查与 Vite 生产构建通过，无构建警告。业务代码约 45 kB，Three.js 约 480 kB，保持相对部署路径。
- Edge 浏览器使用实际 Game 与键盘事件，在测试虚拟时间下完成三圈比赛（约 47.5 秒）：6 次腾空、6 次落地、6 次奖励；前翻、后翻、水平旋转全部出现；最高 216 km/h；所有水平位置位于水道内，结果页及重赛正常。
- 实际浏览器显示最高腾空约 6.32 米、最多约 67 个活跃水花；有界池未溢出，截图已检查腾空、动作、氮气与落水。
- 音频初始化前上下文为空；键盘操作后状态为 running。比赛中同时短音效最多 4 个；50 次密集触发测试仍最多 6 个，持续源固定 3 个。分析器测得非零合成输出，关闭声音后 RMS 明显下降；开关与总音量 UI 正常。此测试验证信号和节点预算，不代替人耳音色评价。
- 原浏览器回归：正常玩家 180 km/h、AI 175/170/165/160 km/h，WASD、碰撞恢复、画质、横屏双指输入、三圈结果与重赛通过。GPU 清屏检查通过，没有历史帧累积。
- 原碰撞场景回归：追尾、擦碰、迎面、AI/AI、拥挤发车、高速接触仍无残留物理重叠和数值异常，碰撞后 AI 继续比赛。
- 浏览器无页面异常、控制台或着色器错误。浏览器脚本和截图位于被 git 忽略的 `.qa`，产品入口没有自动驾驶或快捷完成比赛功能。

## 已知限制与试玩确认

- 飞行采用纵向弹道，空中水平驾驶仍是原街机模型；赛道边界用投影限制，不是真实刚体或地图网格碰撞。
- AI 本阶段保留原水面路线，正常车道绕开跳台，没有 AI 特技或氮气策略。
- 自动特技动画作用于占位船体，没有人物动作；晚触发失败后视觉姿态在落地复位。
- 水花是短寿命点粒子和简化尾浪，没有真实流体或水面反射。碰撞船只的水花反馈完整，持续驾驶尾浪/水花目前主要服务玩家。
- 声音为基础合成音色，没有音乐或真实发动机录音。声音层次、默认音量和持续喷射的听感需要实际试听。
- 真实手机性能与 Safari 音频策略留待 GitHub Pages 部署后专项验证。本阶段未发布到线上。
- 请实际试玩确认跳台宽度/高度、空中转向、动作时间、失误惩罚、氮气 +20% 的冲刺强度及持续时间、水花显眼程度、镜头变化和音量平衡。

Phase 3 到此结束，不进入下一阶段。
