# 玩家计圈与结算修复

玩家未设置 AI 的 `routeIntent`，沿主路内侧驾驶时仍可能在重叠岔口被自动标记为 `tunnel-cut`。旧检查点逻辑只接受该标记对应的分支，因此真实穿过主路 CP12 也不计分；下一检查点一直停在 CP12，圈数和结算被连带阻塞。修复前实际 Game.frame 测试在游戏内 599.97 秒时仍只有 11 个检查点、`1 / 3`，未显示结算。

主路检查点现在以真实的顺向轨迹、门宽和高度判定，不再被提前获取的捷径标记屏蔽。捷径检查点仍要求合法进入对应分支；检查点顺序、逆行、离开水道、高度、瞬移过滤和三圈规则均保留。改动不涉及渲染、模型、材质、水面、阴影、分辨率、驾驶参数或 AI 配速。

验证：

- 176 项自动测试通过，TypeScript 与生产构建通过。新增 CP12 原因复现、全部主路检查点遇到过期路径标记、完整三圈计分与结算冻结测试。
- `browser.json`：生产编译的真实 Game.frame，玩家通过驾驶输入沿主路中央、外侧、内侧和两条捷径行驶；每条路线完整经过 1–72 检查点，圈数正常变化，第三圈显示五人结算表，计时冻结，“再赛一场”重置为第一圈和倒计时。四个截图是对应实际结算画面。
- 玩家测试保留四名实体 AI、碰撞、跳台、特技和氮气；没有瞬移玩家、注入计分或在 CP71 停止。仅在加速功能测试期间跳过 GPU 绘制，截图时恢复；这些结果不能用作帧率数据。
- `ai-pace.json`：实际 Game.frame 复测两组四名 AI 的三圈成绩与修改前完全相同。默认发车约 269.98、303.65、325.38、341.75 秒。
