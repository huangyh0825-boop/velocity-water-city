## 已知限制

- 单一宽阔圆环，没有复杂弯道、精细碰撞和多地图。
- AI 为固定车道路线跟随，无避让、追逐策略或选手间碰撞；内外圈长度影响排名。
- 玩家完赛时立即结算，未完赛 AI 按当时进度排列并标记未完赛，之后不继续模拟比赛。
- 比赛时钟随 60Hz 模拟更新，后台暂停；极低帧率下限制补算时间，避免物理跳跃。
- 手机仅通过浏览器模拟验证，尚未在实体 Android/iOS 上评测兼容性与帧率。
- GitHub Pages 配置保留，尚未在线部署。

第二阶段到此结束。未加入氮气、特技、复杂特效、商店或多地图。
