# 驾驶速度与运动清晰度调优

日期：2026-10-13。范围仅为速度参数和运动画面优化，保留当前竞速系统，未新增大型功能。

## 参数变化

| 项目 | 原值 | 新值 |
| --- | --- | --- |
| 玩家极速 | 38 m/s（136.8 km/h） | 50 m/s（180 km/h） |
| 玩家全油门推力 | 9.5 m/s² | 起步 14，高速逐渐降至 10 m/s² |
| 普通 AI 极速 | 115.2 / 108 / 100.8 / 93.6 km/h | 175 / 170 / 165 / 160 km/h |
| AI 加速度 | 7.5 m/s² | 12 m/s² |
| 尾浪寿命 | 2.4 秒 | 1.15 秒 |
| 尾浪峰值透明度 | 0.26 | 0.18，并随寿命平方淡出 |

玩家原有刹车、阻力、转向平滑和侧滑惯性保持不变。转向使用独立的原 38 m/s 参考速度：原速度范围内响应一致，更高速度下保持原高速转向上限。摄像机文件和输入文件未修改，镜头仍使用原跟随延迟和 FOV 范围。

## 残影排查与处理

代码中没有 EffectComposer、动态模糊、TAA、Afterimage 或历史帧累积。渲染器原本就默认逐帧清屏；本次显式设定 autoClear=true、preserveDrawingBuffer=false，确保后续不会意外保留旧缓冲。

发现的可优化项是物理位置直接以 60Hz 呈现，以及尾浪透明叠加较明显。新增仅用于显示的姿态插值，让玩家、AI 和镜头在物理步进之间使用连续位置，物理和输入仍以原固定步长计算。返回赛道、重赛、后台切换和完赛都会重置插值历史，防止模型跨场景拖动。插值有约一个模拟步长的显示延迟（上限约 16.7ms），不改变物理转向响应。

尾浪仍存在，但寿命缩短、透明度降低，产生点移到船尾之后并随寿命淡出。未通过新增动态模糊制造速度感。

## 文件变化及原因

新增：

- `src/config/speed.ts`：集中玩家与普通 AI 的速度、加速度参数，统一单位转换，方便后续调参。
- `src/player/MotionInterpolation.ts`：显示姿态插值，与实际驾驶模型分离。
- `tests/speed-rendering.test.ts`：5 项速度稳定性、AI、转向回归、插值和重置测试。
- 本记录。

修改：

- `src/player/DrivingModel.ts`：180 km/h 上限、渐进加速曲线；转向参考速度与极速解耦。
- `src/ai/AIController.ts`：可配置基础加速度，不增加 AI 策略。
- `src/core/Game.ts`：接入普通 AI 速度、显示插值和插值重置，显式设置清屏。
- `src/player/Watercraft.ts`：支持显示姿态，俯仰按新极速归一化，避免旧硬编码造成过度抬头。
- `src/effects/Wake.ts`：更短、更淡并随寿命消散的尾浪，重置立即清除尾浪透明度。
- `tests/driving.test.ts`、`tests/race.test.ts`：更新速度期望和实际 AI 参数，保留竞速回归。
- `README.md`：更新参数、调节入口与测试说明。

## 测试结果

- `npm test`：17/17 通过。原有驾驶/竞速回归、三圈完赛、边界、AI 排名、转向响应和插值重置均通过。
- 独立驾驶测量：0–100 km/h 约 2.35 秒，0–180 km/h 约 4.70 秒；持续全油门保持 180 km/h，无限速振荡。
- `npm run build`：TypeScript 检查与 Vite 生产构建通过，无构建警告。
- 生产页面：WASD、刹车、恢复位置、重赛和画质切换通过。
- 横屏触摸模拟：方向与加速多指同时输入、触点释放均通过。
- 使用实际 Game 与键盘事件完成三圈（约 49.83 秒），验证结果页、计时冻结和再赛一场。
- 浏览器记录实际最高速度：玩家 180 km/h，四位 AI 为 175/170/165/160 km/h。
- GPU 缓冲验证：隐藏玩家模型后下一次渲染像素改变；重复渲染完全相同的场景，像素保持一致，确认没有累积旧帧。180 km/h 截图已目视检查。
- 浏览器验证无页面异常、控制台错误或着色器编译错误。本地验证脚本与截图仍在被 git 忽略的 `.qa` 目录。

设备屏幕响应时间、实际浏览器刷新率和实体手机性能仍需试玩确认；此验证不能排除显示设备自身的运动拖影。未改赛道、比赛规则、AI 路线或加入氮气、特技、商店等功能。
