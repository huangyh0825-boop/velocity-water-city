# 手机双键操作

实现用户选择的“双键轻松驾驶”。本文件记录触控实现；随后增加的手机标准画质与桌面性能调整见 [手机标准画质](mobile-quality/README.md)。服务器协议、赛道、驾驶与碰撞规则、AI 参数保持不变。

- 左侧为带拖影线的实心方向箭头，移除可见“左转 / 右转”文字，保留无障碍名称；按下时有短距离位移与亮色反馈，没有待机循环动画。右侧刹车踏板图标保留“减速”文字，与设置入口区分。
- 手机自动加速等价于持续按原有 W；按住减速时释放油门并抑制氮气，松手恢复。方向与氮气可由双拇指同时操作。电脑继续使用原来的手动键盘输入。
- 特技仅在比赛进行中、合法腾空且尚未使用时可点；氮气耗尽、等待发车、完赛等状态同步禁用相关触控。原有五秒联机倒计时和服务器加载屏障不变。
- 支持原生多点触控和指针捕获；移出图标后仍保持按下，取消触控、失焦、打开设置、退出比赛会清理持有输入。设置位于右上角，打开时暂停自动油门输入；它不是联机暂停。
- 移动教程按设备显示箭头、自动加速与技能触控说明；按键图标为内嵌 SVG，无新增图片请求。按钮状态和能量文本仅在值变化时更新，无新增循环或计时器。

验证：231 项 Node 测试、TypeScript 检查和生产构建通过。`scripts/qa/mobile-controls-browser.mjs` 在实际游戏中通过原生 CDP 多点触控、取消捕获、真实加速/制动、空中特技、画质切换、设置/完赛/重开清理、桌面键盘回归。覆盖 844×390、740×360、667×375、568×320、390×844、320×640、1024×768，按钮无重叠或越界，触摸目标至少 44px。

`QA_TOUCH=1` 的双浏览器联机验收通过：延迟其中一人加载时保持等待，全员加载后统一五秒倒计时，两端无需长按油门即可驾驶，掉线恢复、一分钟通信与返回首页正常。这里是浏览器手机模拟，未声称完成 iPhone / Android 实机验收或测得 FPS 提升。

私有测试入口为 `scripts/qa/mobile-controls-view.html`，生产入口不导出任何 QA 对象。截图和完整结果位于忽略目录 `work/mobile-dual-controls` 和 `work/mobile-dual-online`。
