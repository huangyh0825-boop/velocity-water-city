# 正式 GitHub 游戏接入 Render 大厅

截图中的正式游戏原本仍使用 Cloudflare，且初次健康检查最多等待 6 秒；此前可用的 Render 测试页是独立入口。本次把正式 GitHub Pages 的 `VITE_LOBBY_URL` 设置为实际部署并实测过的 `https://velocity-water-city-lobby-test.onrender.com/api/lobby`。

首页现在在用户点击入房后按需唤醒服务，单次健康检查最长 20 秒、整体初次连接最多 3 分钟，重试网络失败/唤醒 HTML/暂时不可用的服务，并显示耗时、重试提示和取消按钮。取消、返回训练、销毁首页均会终止等待，迟到的回调不会更新旧页面。房满、身份无效和 Origin 未授权等明确拒绝不会反复重试。原 HTTP 大厅兼容保留，原 WebSocket 心跳与入房后的指数退避重连保留。

服务器重启或离线超出席位保留时间后，检测成员 ID 变化，提示“原席位已失效，已重新加入，请重新准备”。这不改变本机设备档案。多人仍为房间大厅及准备阶段，未实现联机竞速。

验证：205 项 Node 测试、13 项 workerd 测试、类型检查及生产构建通过。`local-browser.json` 是把待发布静态构建仅在本机浏览器映射到正式 Origin 的预览验收，后台为真实 Render；验证 503/唤醒 HTML、超过原六秒的健康检查、取消、三客户端同房、准备、断网重连、退出、房主移交和手机布局。它不代替真实 Pages 发布后的验收；上线结果单独记录。

游戏模块除入口导入文件名外与原正式版本字节一致，见 `game-core-unchanged.json`。3D、模型、物理、赛道、AI 和画质均未修改；主页连接等待计时只在用户等待入房时运行，结束/取消后清理，无常驻探活。

用户已回传中国大陆移动网络、VPN 关闭的实际 HTTP/WSS 成功报告，首次入房约 2.33 秒；两次中断由用户明确说明为主动离开页面。此前本机浏览器完整五分钟观察零断线。其他网络路径仍可能出现握手超时，不承诺所有运营商均稳定，Render Free 也会休眠/重启。免费账号无银行卡，没有新增付费服务、域名或第三方探活。

正式切换后只需打开原 GitHub 游戏网址，无需打开独立测试页。更新时用带本次版本参数的链接重新打开或强制刷新；旧页面重试入房不会重新加载 JS。

Cloudflare Worker、Durable Object 及代码保留。若需回退，将 GitHub Actions 仓库变量 `VITE_LOBBY_URL` 恢复为 `https://velocity-water-city-lobby.huangyh0825.workers.dev/api/lobby` 并重新发布 Pages；不要仅上传源文件就宣称回退生效。
