# 手机提示位置与比赛手势

- “自动加速 / 按住减速”移到右侧刹车上方，分成两行；为它留出特技与刹车之间的空间。7 种横竖屏尺寸验证提示和所有按键无重叠。
- 手机比赛根容器设置 `touch-action: none`，覆盖按键、水面、HUD 和空白处；增加可取消的多指触摸及 Safari gesture 事件保护。单指点击仍交给原菜单和控件。
- 防护随 InputController 生命周期安装/卸载；返回首页恢复原手势策略，电脑输入保持原逻辑。没有修改 viewport 的缩放上限、渲染、素材、物理或联网协议。
- 245 项 Node 测试与 TypeScript 检查通过。真实浏览器触摸事件验证多指默认手势被取消，同时转向 + 氮气、滑出后的指针捕获、刹车优先、特技、设置、结束、回首页再开局及桌面按键均通过。

Windows headless Edge 在未加保护的基线页上也不能通过 CDP 合成手势观察到视口缩放，因此未将“scale 未变化”冒充原生缩放测试。浏览器记录验证触摸事件默认行为取消、CSS 策略和 Safari 兼容事件处理；尚无实体 iPhone/安卓手机缩放验收。
