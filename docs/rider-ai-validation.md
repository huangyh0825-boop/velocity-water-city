# R4车手与AI视觉同步 · 验收记录

本轮仅改人物视觉、同级AI资产选择、独立队色/局部阴影及相关验证。检查点 rider-ai-baseline 保留旧版。水面、赛道、建筑、艇身资产及速度/碰撞/AI决策/比赛规则未改；76项受保护源文件及艇身/贴图/低档资产逐项哈希相同，详见截图目录中的protected-files.json。

## 实际完成的改动

- 沿用官方Blender CC0真实成年人基础和原有坐姿皮肤，收紧上臂/前臂/腿部的额外服装膨胀量，并在肩部局部加宽最多13mm/侧。没有更改手脚物理挂点，也没有宣称重新扫描或完整重建人体。
- 头盔相对R3宽91%、高90%、深94%，重塑下颌/后颈轮廓、眼口密封和中性半透明面罩；真实CC0面部在镜片后保留。透明镜片不再在局部深度图中当成不透明物遮黑整张脸。皮肤仍是简单材质，不是高质量扫描皮肤。
- 浮力背心从平板改为逐点沿胸背人体曲面贴合；凹领、袖窿、弧形绗缝、扁平调节织带和拉链形成可穿戴结构。肩/前臂/膝/大腿护片用隐式曲线裁切原蒙皮，边缘插值骨骼权重；修复第一轮中出现的锯齿边缘。领套使用胸椎到颈部的渐变权重。
- 绑定由43扩展为46骨骼：新增胸椎、左右锁骨，重新接入肩臂及颈部，重新分配局部躯干权重；保留28指骨。不是整套全新绑定或动作捕捉。骨盆/腿脚接触不动，上身分段弯曲、头部回正，握把IK固定手位和手掌方向。加速、转弯、空中和落水回弹均为视觉响应；特技继承整艇视觉组。
- 玩家和四名AI标准画质使用完全相同的watercraft.glb、rider.glb及贴图；每艘约4,927,792三角面（含视觉附属物）。原AI固定低模路径已取消。使用蓝、橙、紫、金、薄荷队色，材质与骨骼实例独立，几何/贴图共享。当前几何、装备、编号07相同，仅配色不同。用户主动选择低画质时全体一起回退，标准画质不按AI身份降档。
- AI与玩家同级2048²局部自阴影和同一环境反射。只跳过视锥外AI的无效自阴影绘制，不降低可见模型精度；多人近距离同屏仍增加开销。

## 实际验证

主要修改文件：`scripts/art/rebuild-rider-r4.py`、`assets/racecraft/source/hero-rider-r4.blend`、`public/models/rider.glb`及`rider-r4/textures/`、`manifest.json`；运行侧为`src/player/RacerMaterials.ts`、`AnatomicalRider.ts`、`Rider.ts`、`Watercraft.ts`、`HeroLighting.ts`和`src/core/Game.ts`中的视觉接入。新增`tests/rider-ai.test.ts`、更新角色资产契约测试；`scripts/qa/rider-ai-*`保存复现、截图、源文件及资源哈希验证流程。

- TypeScript --noEmit通过；107项自动化测试通过；Vite生产构建通过。保留原有Three.js大分块体积提示，非构建失败。
- 新增测试：材质/纹理共享边界及独立队色/销毁、46骨骼分段骑姿下手脚锚点、独立阴影层/透明面罩、屏幕外阴影跳过与入镜恢复。原有30/60/120调度、碰撞/跳台、三圈检查点、AI特技/氮气等模拟回归继续通过。
- Edge实际游戏加载五套同级模型，五套独立骨骼，队色互不覆盖；资源/着色器/脚本无错误。键盘驾驶图速度约149.2km/h；并排行驶夹具中玩家146.4、AI149.0km/h，间距3.21m。
- 浏览器氮气达到216km/h；真实跳台离水、按空格完成特技、安全落地，氮气从20.2%到55.2%，奖励+35只结算一次。
- 生产预览http://localhost:5174/：模型及PNG请求全部200；W加速、A转向、S减速与重开验证通过，刹车41→0km/h；重开40%氮气；生产页没有window.testGame测试接口。
- 标准画质1600×1000、DPR1、RTX4060 Laptop、无头Edge、120帧普通驾驶：平均30.10ms，约33.2FPS，P95=100.00ms，速度144.2→180.0km/h。这是短采样，不保证持续帧率或60FPS。最初无视锥跳过的实现约97ms/帧，已移除该无效开销；不是对旧版美术的严格A/B性能结论。
- 高低画质切换两轮，标准画质资源计数两次相同：{"geometries":443,"textures":177}。重新开始清空尾浪/水花/腾空/特技状态，氮气40%；销毁再建Game未出现着色器错误。
