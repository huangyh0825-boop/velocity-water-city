# 第五阶段试玩验收记录

日期：2026-10-14。范围：空中混音、赛道重设计、原创 GLB 视觉资源、未来城市和轻量材质优化。未部署 GitHub Pages。

## 检查与保护

原目录没有 Git 历史，先初始化仓库并完整保存可运行基线 `2b96873`，标签 `phase4-checkpoint`。后续分别提交音频、赛道、赛道回归、模型及城市。可通过 `git log --oneline` 查看；切回基线前应另存后续修改。

检查确认已有共享跳台、弹道、玩家/AI 特技、有限氮气、胶囊碰撞和水花/尾浪池。AI 原本已能通过特技落地获得氮气并有限使用；未重复开发一套机制。原来的沿圆环运动不适合新赛道，因此只替换 AI 导航/曲率预判和实际水平位置积分。

保留正常 50 m/s（180 km/h）、氮气倍率 1.2（216 km/h）、玩家加速度 14→10 m/s²、水面阻力、刹车 17 m/s²、转向上限 0.67 及响应 3.5、侧滑恢复 3.8。AI 正常速度目标仍为 175/170/165/160 km/h，加速度仍为 12。氮气初始 40%、消耗 22%/s、成功特技奖励 35% 等规则不变。

为适配更大的空间，将 DrivingModel 的旧 680 米世界限位参数化，生产地图设为 3000 米；旧默认值供原回归测试保留。船间碰撞胶囊尺寸、分离/冲量、垂直高度差过滤和高速细分检测未修改。摄像机、键盘/触控和水花预算保留。

## 已完成内容

### 空中音效

AudioMix 从真正的 airborne 状态区分上坡与飞行。离水时水流/破浪目标增益归零，时间常数 0.035 秒；空中保留油门驱动发动机、风声及氮气。落水使用原瞬态合成音，水面混音以 0.1 秒时间常数恢复。跳台平台接触不错误播放水面落水音。

四个 AI 复用相同混音，按距离衰减、140 米外静音；近场起跳/落水、氮气启动和碰撞也有衰减。持续声源固定为七个（两个玩家发动机振荡器、共享噪声、四个 AI 发动机），短声音上限六个，不随每帧速度变化重复创建声源。音量、静音和首次交互解锁继续有效。

### 新赛道

旧环长约 754 米，新主线长 4,745.34 米，约为旧版 6.3 倍。使用原创闭合样条和弧长采样；曲率变化、连续 S 弯、长直道、宽窄段及六个区域成为实际导航几何。主线全宽 30–56 米，平滑过渡。

24 个顺序门/圈，三圈需要 72 次有效穿越。两条窄捷径分别宽 14/16 米，比对应主线路段短约 100/66 米；捷径上的门与主线对应同一个逻辑 ID，仍必须按序通过。岸壁在合法合流口打开，水道约束使用主线/捷径走廊并集，未关闭碰撞。

三处跳台放在低曲率段（主线进度约 28%、38%、87.6%），使用实际航向与原共享艇体支撑/扫掠路径触发。AI 提前约 220 米选择和对准跳台，根据曲率限速及路况使用氮气。空中仍由共享弹道积分，落地回归实际路线；恢复位置改为最近有效门之后 10 米。

### 模型、角色与环境

未发现可用 Blender，采用真实曲面建模替代流程：原创截面曲线放样、封口和面板轮廓，导出 GLB 后由 GLTFLoader 加载。艇身是连续曲面，增加独立座椅、握把、仪表玻璃、挡风罩、接缝、脚踏、双尾喷及灯带。驾驶员具有曲面躯干/四肢、完整头盔、护甲、手套和靴子。分层动作保留固定握把、加速前倾、侧倾、跟随腾空/特技，并增加落地缓冲。没有专业手工雕刻、布料模拟或骨骼蒙皮。

四个 GLB 总计约 3.06 MB。标准艇/驾驶员约 29,192 三角面，低精度约 15,376；AI 共用低精度模板，静态艇身按五个材质组合并。异步加载失败有原模型兜底，资源路径使用 Vite BASE_URL。

城市包括分区的层叠楼宇、斜顶玻璃塔、旋转曲面塔楼、仓库屋顶/码头吊机、岸台、三种桥梁、主线/支线隧道、高架轨道和六区标牌。建筑采用原创模块化程序几何，仍未达到专业手工城市资产的细节水平。

材质使用静态 PMREM 环境反射、金属/塑料/玻璃差异；接触阴影是简单平面近似，低画质关闭。水面仍采用轻量多方向波纹/日光高光，沿用 V 形尾浪和对象池水花。没有历史帧叠加、运动模糊、实时反射追踪或新增复杂流体模拟。

## 实际测试结果

- `npm test`：75/75 通过，66 项原测试保留。最新完整运行约 12.6 秒。
- `npm run build`：TypeScript `tsc --noEmit` 和 Vite 生产构建通过。Three.js 块仍为约 553.71 kB，Vite 提示超过 500 kB；没有隐藏该告警。业务块约 83.17 kB，模型加载器约 43.79 kB。
- Node 模拟：玩家自动驾驶和 AI 各通过 72 个门；四个 AI 实体拥挤起跑测试全部完成三圈，检查每步船体分离、有限能量、有效位置、跳跃和特技奖励。非法漏点/逆行/瞬移拒绝，两条捷径按序计分。
- 新样条跳台针对性测试：同一步发生实体碰撞位置修正仍可合法起跳，只触发一次，随后垂直速度不被覆盖。既有跳台/碰撞/频率回归继续通过。
- Edge 实际 Game 浏览器自动驾驶：首圈不用氮气 109.18 秒，三圈 319.38 秒；玩家 72 门、9 次跳跃/落地、9 次特技奖励，最高 216 km/h。AI 起跳次数 6/6/3/5、奖励次数 5/6/2/3。没有浏览器异常。此脚本生成控制输入，不瞬移艇身；使用虚拟时钟推进比赛，不能作为真实性能测量。该理想路线没有自然船间接触，接触验证来自专项模拟。
- 重新开始：清除旧比赛状态、计时/结果、恢复 40% 氮气。玩家完赛立即结算是原规则，因此当时未完赛的 AI 仍显示未完赛；独立物理模拟继续跑到全部 AI 完赛验证。
- 实际 AudioParam：水面增益约 0.052→0→0.062，空中风声 0→0.059→接近零；发动机继续运行，空中氮气增益约 0.10，持续声源数保持七。验证了目标增益和浏览器音频运行，尚未进行人耳听感验收。
- 标准/低画质模型均实际加载；低画质水花预算 96，资源接口没有报错。GLB 自动解析验证几何有限值、节点名称、艇身尺寸及低精度面数。
- 生产预览 `http://127.0.0.1:5174/`：四个 GLB 均 HTTP 200；真实键盘 W 加速到 HUD 91 km/h，A 转向、S 制动降至零；重赛重置正常，生产页面不存在测试专用 Game 全局入口。
- 无虚拟时钟性能采样：Edge 无头、1440×900、RTX 4060 Laptop，5 秒持续驾驶样本约 239.8 FPS，帧间隔 P95 4.3 ms，超过 50 ms 的帧为零；最多 212 次绘制、约 227,379 三角面。这只是该硬件/短场景样本，不能保证其他设备或全赛程达到同样 FPS。

## 未完成和需要试玩确认

没有人工完整驾驶三圈、人耳听感评估或真实手机调试；浏览器完整比赛采用自动输入。主线自动输入验证不等于每一种人工轨迹都已覆盖，尤其捷径出入口碰撞、急 S 弯、跳台边缘和碰撞后落地需要试玩确认。

模型为原创代码曲面 GLB，未完成 Blender 手工精修、烘焙纹理、人体骨骼蒙皮或专业美术质量验收。城市仍是模块化程序建筑。没有真实阴影贴图或水面实时反射；接触阴影是近似。没有资产压缩，初次加载仍约 3.06 MB。

新路线使用水平走廊投影约束；桥梁/隧道为有净空的视觉结构，没有加入屋顶刚体碰撞。AI 是简单曲率导航，没有复杂捷径策略或战术超车。单圈 90–120 秒目前由自动驾驶确认，还应根据用户手动试玩反馈调整路线。

检查发现原项目未实现跨比赛持久最佳成绩记录；本阶段保留现有当场结果，没有声称已有持久存储。若要补齐，应作为单独明确任务处理。

本阶段到此停止，等待试玩及美术验收；没有新增商店、货币、升级、联网或自动部署。
