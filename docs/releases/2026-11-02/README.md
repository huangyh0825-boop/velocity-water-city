## 公网冷启动复查后的加载修复

首批版本部署后，当前测试网络上的实际浏览器启动先后超过 4 分钟和 10 分钟，持续下载但发生多次连接关闭和重试，不能算公网启动通过。单独的 1 MiB Range 请求也超时；同一文件拆成四个 256 KiB Range，约 2.9 秒完成且拼接 SHA256 正确。该结果描述当前测试网络，不代表所有地区、运营商或设备。

- 下载从最多 256 KiB 的分片开始；快速连接可逐步增至原来的 1 MiB 上限，失败时缩回小分片并重试同一偏移。已完成部分和完整文件仍可缓存复用。
- HEAD 预检超时后继续尝试 Range，避免未经确认就切换成大文件整包重传。明确的编码响应仍保留完整解码回退，版本变化仍禁止混接。
- 压缩响应转为完整下载前，先释放旧分片的计时器，防止完整响应仍有数据流入时被旧计时器提前中断。
- 增加四个回归测试，完整测试现在为 **259 项通过**。覆盖超时后分片、未知编码回退、慢速编码响应计时器、分片缩小和旧大分片缓存兼容。
- 将 public 资源设为原始字节存储，避免 Windows 自动换行让资源缓存版本与 GitHub/Linux 不一致。既有资源字节与 Git 内源文件一致，资源版本恢复为 `88c9388eafb9`，没有修改模型、纹理或解码器内容。
- 使用修复后的实际下载代码，在公开游戏域名的浏览器中完成 28,635,328 字节快艇模型的下载并核对完整 SHA256，用时约 235 秒、重试两次。没有用代理转发或本机模型替换这项公网下载。
