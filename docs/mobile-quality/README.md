# 手机标准画质与电脑性能

基线：`ccac540`（手机双键操作本地检查点）。发布仅更新 GitHub Pages 前端和独立手机素材；大厅协议与服务器、赛道、驾驶、碰撞、AI 和计圈规则没有变化。

## 画质预算

| 项目 | 原手机低画质 | 新手机标准 | 电脑标准，保持原值 |
| --- | --- | --- | --- |
| 摩托 + 骑手三角面 | 31,540 | 334,594 | 4,927,760 |
| 摩托材质 | 低画质素材 | 原 PBR 通道，贴图长边最多 1024px | 原素材与原贴图 |
| 基础水面网格 | 64×64 | 160×160 | 320×320 |
| 每帧平面反射 | 关闭 | 512×512 | 1024×1024 |
| 城市 / 摩托阴影 | 关闭 | 1024×1024 | 2048×2048 |
| DPR 上限 | 1 | 1，绘制长边最多 1024px | 1.75 |
| 建筑近 / 远 LOD 距离 | 70 / 210m | 180 / 450m | 375 / 800m |

手机默认使用新标准档，仍可切换低档。保留完整城市、近景材质、船体轮廓、角色骨骼和动作、波浪及尾浪细节、动态倒影和阴影。`*-mobile.glb.gz` 与 `mobile-textures/` 为独立资产；原桌面素材和低画质素材均保留。离线生成方法：先运行 `scripts/pack-mobile-textures.py`（Pillow），再运行 `node scripts/build-mobile-models.mjs`。生成器保留所选顶点的原始属性，约束轮廓误差，并输出 [素材统计](models.json)。运行时不会在手机启动时请求桌面 `*-packed.glb.gz`。

## 电脑优化

仅缓存不移动的城市、道路与高架 Object3D 变换；实例矩阵、可见性、动画时间、材质仍实时更新，摩托与骨骼不进入静态缓存。建筑 LOD 归属未变时跳过重复实例矩阵上传和包围球重算；HUD 文本与状态值未变时跳过 DOM 写入。电脑分辨率、模型、贴图、建筑 LOD、阴影、水面和反射参数均保持原值。

## 验证与限制

- 236 项 Node 测试、前端 / Node 大厅 / Workers 类型检查和 13 项真实 Workers 测试通过。
- 手机浏览器模拟：真实 CDP 多点触控，减速 / 特技 / 设置 / 重开、7 种屏幕尺寸、标准与低档切换、桌面 W 键回归；无页面异常。
- 新模型检查索引范围、属性完整性、原材质与骨骼节点、握把定位，以及倾斜 / 转弯 / 腾空姿态下蒙皮顶点有限且未发散。
- 844×390、DPR3、五台同屏：原低档 6,500,306、原标准档 68,212,993、新手机标准档 16,755,304 个绘制三角面（含额外渲染遍次）。新标准比原标准减少约 75.4%；它仍比低档保留更多细节。结果是同一桌面 GPU 的浏览器手机模拟，不能代替真实手机 FPS。
- 1600×1000、DPR1、两处固定桌面视角，前后截图 RGB 像素完全一致；对照路线的绘制次数、三角面数、物理终点和检查点记录一致。完整帧 ABBA 测量有明显波动，不把它解释为固定帧率提升；另有静态场景矩阵更新的隔离 CPU 测量。
- 双手机浏览器实际联机验证全员加载屏障、五秒倒计时、自动加速、对手同步、掉线恢复和一分钟通信；生产页面无 QA 导出。

本地完整证据在忽略目录 `work/mobile-quality/`、`work/mobile-quality-controls/` 和 `work/mobile-quality-online/`。公开部署必须等 GitHub Actions 成功，并比较公开入口和 Game 模块的完整 SHA256 后再确认生效。
