## 新增表现

1. **水面与特效**：低振幅双向顶点波、四方向解析法线、日光高光、视角相关水色及远景雾。没有实时反射纹理或历史帧处理。五艘艇共用世界锚定 V 形泡沫，速度控制宽度与透明度；1.45s 扩散消散。粒子淡入/淡出，转弯外侧发射增强；AI 也有持续尾浪和跳跃/落水水花。落在跳台而非水面时不发落水水花。原碰撞位置、强度与 EventLimiter 冷却继续用于玩家/AI、AI/AI。
2. **艇身与驾驶员**：低多边形流线壳体与蓝银上层、座椅、双推进器、灯带、侧向进气口、挡风板、脚踏；金属、塑料和玻璃材质分开。静态部件按材质合并。玩家和 AI 加入程序化头盔赛车服角色，速度与加速影响平滑前倾、转向影响侧倾，固定握把及两段手臂。驾驶员属于 visual，跟随特技而不改变物理朝向；膝腿和脚踏根据近景截图调整，正常、侧倾及翻转未见明显穿模。
3. **晴日城市**：36 座不同高度近景玻璃楼群，保留中心城市和远景天际线；三座跨水道桥，原创广告牌、岸边灯柱和城市岸台。桥底 18m，支撑在驾驶边界之外；赛道路线、门、跳台、内外边界不变。加入晴天渐变天空和太阳盘，ACES 输出控制高光，不加运动模糊。
4. **音效**：连续发动机滤波随速度/油门平滑变化；原氮气、破浪、起跳、落水、碰撞声音保留。补充 3/2/1/GO 音调，每个数字一次；用户未交互时保持静音，不补播过期提示。主混音增加 DynamicsCompressor 峰值保护；短声音共同最多 6 个，持续源仍 3 个，音量/静音入口保留。

## 实际验证

- 逐步结果：原基线 57 → 水面/特效 60 → 模型 62 → 城市 64 → 音频 66。最终 **66/66 自动化测试通过**，无跳过；保留原所有驾驶、碰撞、AI、跳台、三圈、排名、奖励和 30/60/120 调度回归。
- `npm run build`（`tsc --noEmit && vite build`）通过，无构建警告。业务 JS 71.20kB / gzip25.03kB，Three.js 483.76kB / gzip121.19kB。宿主 npm 不在 PATH，通过已安装运行时 pnpm 执行相同 npm@10 脚本。
- Edge 生产页面：加载、WASD、刹车、恢复、重赛、低画质、横屏双指触控模拟通过；三圈约 50.76s，结果五名选手、冻结计时及重赛通过。普通玩家峰值180，AI 氮气峰值[210,204,198,192]，与原参数一致。
- Edge 玩家特技回归：9 次起跳/落地，6 次安全特技奖励，三种动作均出现，最高216km/h；音频交互解锁、非零输出、静音、音量、粒子/音源预算通过。
- Edge 跳台场景：无碰撞、右侧并排、追尾、侧撞、高速、碰撞同一步越过坡沿均正常且不重复起跳；边缘/低速不强制起飞。同高度空中相撞、有高度差不误撞、坡面着陆一次通过。检测的最终同高度水平船身重叠为0。
- Edge AI 完整循环：四名 AI 均跳跃、做特技、取得能量并使用氮气，恢复比赛进度。最后一次测试起跳[7,4,4,4]、奖励[5,3,3,3]；玩家24个合法检查点后结算，两个 AI 尚未完赛保持原行为，独立五艇测试覆盖所有 AI 完成三圈。
- Edge 原六种碰撞场景：追尾、擦碰、迎面、AI/AI、拥挤发车、高速运动，无残留重叠/非有限数值，AI 碰撞后继续行驶。
- GPU 清屏：隐藏整个玩家模型后画面立即清除；连续相同状态渲染像素一致，没有历史帧叠加或重新引入船体残影。
- 新视觉浏览器检查：近景、驾驶、驾驶员随翻转、低画质截图已查看；特技旋转不改变物理 heading。五艇粒子有界，停止发射后清零。所有几何首次 GPU 上传预热后25次重新开始，纹理18→18、几何200→200；这是资源数量检查，不是完整堆内存证明。销毁 Game 后 canvas 为0、AudioContext closed，未出现页面或控制台 error。
- 倒计时用户解锁后实际3/2/1/GO各一次；50次提示音密集触发最多6个短音源、3个持续源。满音量抽样混音输出峰值约 .54（<1）；验证了信号和预算，不替代听感评价。

### 性能测量范围

本机 Edge headless、ANGLE Direct3D11、**RTX 4060 Laptop GPU**、1440×900、标准画质、实际 RAF 五秒采样：平均约240FPS，中位帧4.2ms、P95 4.3ms；CPU render 提交P95约.9ms，最大134绘制调用、75,750三角形，0帧超过50ms。该采样包括五艇实际驾驶/跳跃，但玩家直行后碰墙减速，不代表全程竞速或所有视角负载。低画质近景抽样68绘制调用。不能据此保证普通集显、真实手机或所有浏览器都60FPS。

## 限制与重点试玩

- 模型为原创程序化低多边形风格；没有人物骨骼或复杂衣服物理，暂不追求真实人物/艇身细节。特殊遮挡和极端视角仍需人工确认。
- 水面高光为解析近似，不会真实反射建筑；没有真实流体、动态阴影或屏幕空间反射。V 尾浪/水花为短寿命泡沫与点粒子。
- 声音为合成音色，没有音乐或真实发动机素材；请重点听高速持续声音、氮气与落水叠加后的舒适度。
- 没有人类手动试玩、真实手机/Safari 实测或低端设备长时性能测试；触控入口仅做浏览器模拟回归。
- 当前项目没有持久化最佳成绩模块，已保留单场计时/结果，没有自行扩展成绩存储。
- 重点试玩：高速转弯的外侧水花与V尾浪辨识度，落水/相撞反馈是否适度，前后翻/旋转时人物姿态，广告/桥梁是否影响赛道视野，低画质效果，以及声音音量平衡。
