# 捷径岔口空气墙修复复查

2026-10-19。本地修订已构建，尚未推送或更新 GitHub Pages。

用户补充两张仍显示“触碰边界”的截图后，扩大检查发现：上一版只在预设入口/出口百分比内合并两条水道，遗漏了范围外仍然合法的主路，以及折返后尚未更新的路线标记。初始排查的 978 组位置/朝向组合中，204 组发生错误限位；一个合法主路位置甚至被拉向约 25m 外的捷径。截图本身不包含世界坐标，本轮没有把合成测试位置冒称为截图中的精确坐标。

本轮修改 CityTrack 的物理水道选择：

- 碰撞不再受捷径入口/出口百分比或比赛路线标记限制；合法的同层主路和捷径都可通行。
- 路线标记滞后时，依据快艇位置与高度找回实际水面，避免远处捷径的边界、坡道高度影响当前主路。水面缓存也随艇身高度变化失效。
- 保留艇身朝向所需的边距；当两边都不能容纳艇身时，保留原有碰撞恢复方向，防止把快艇推入两条水道之间的实体岸体。
- 不同高度的水道仍独立判定。驾驶参数、比赛计分规则、AI 决策、跳台、特技、氮气与画质配置未调整。

验证：

- TypeScript 检查、生产构建通过，162/162 自动化测试通过；日志见 tests-final.txt。
- 同一组 978 个位置/朝向组合，修复后错误限位为 0；扩展到 5/40/100/160 km/h 共 3,912 组，位置、速度、水平动量均保持不变。
- 新增真实驾驶回归：在旧入口范围外的主路上，带有错误捷径标记从 5 km/h 起步，沿主路继续 80m，两条捷径均通过。
- 既有 18 组手动进入、驶出捷径，以及玩家与 AI 三圈/72 检查点、五艇比赛、飞跃和高低水道隔离回归均通过。
- 浏览器私有生产构建使用实际 Game.frame：两条主路与两条完整捷径共 4 条路径通过；另有 24 组低速改道/折返，覆盖两条捷径、主路/支路、入口/旧范围外/出口、正向/反向，均从 5 km/h 行驶 20m，加速到约 40 km/h，合法水面中的错误限位和位置强制修正均为 0。详见 browser.json、maneuvers.json。
- 上述浏览器功能测试在固定 60Hz 模拟期间跳过 GPU 绘制，结束后恢复渲染并截图，不作为实时 FPS 证明。
