# 极速水城：未来竞速

TypeScript + Three.js + Vite 原创网页水上竞速原型。当前完成第三阶段：在原三圈比赛、4 位 AI 和实体碰撞基础上加入 3 处跳台、自动空中特技、氮气冲刺、动态水花和原创合成音效。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

手机与电脑连接同一局域网，使用终端显示的 Network 地址访问。推荐横屏，手机默认低画质；若无法访问，请检查网络和防火墙端口。

## 比赛与操作

进入页面后倒计时 3 秒，然后开始三圈竞速。W 加速、S 减速、A/D 转向，也支持方向键。空中按一次空格触发自动特技；按住 Shift 使用氮气，松开停止消耗。手机保留方向、加速与刹车，并提供特技和氮气独立按钮。正常驾驶惯性、转向和基础镜头参数保留。

赛道中部有 3 处绿色边缘跳台，速度越高，跳得越高、越远。充足腾空时间下自动选择前空翻、后空翻、水平旋转；每次跳跃只接受一次特技。完成动作并安全落地奖励 35% 氮气，晚触发或落地失误短暂减速。特技不会旋转真实碰撞体。

每场初始氮气 40%，最大 100%，每秒消耗 22%。氮气最高 216 km/h，比正常极速高 20%；带蓝色喷射和适度镜头变化，耗尽后平滑恢复正常上限。返回赛道保留现有能量，重新比赛恢复初始能量。

水花随速度、转弯、起跳、落水和碰撞变化，腾空不生成贴水尾浪。PC 水花池最多 360 个粒子，低画质最多 96 个。音效在首次用户键盘/触控操作后启动，右上角可关闭或调音量；发动机、水流、氮气、落水和碰撞声音均由 Web Audio 原创合成。

第四阶段增加多方向水纹、日光高光和水面明暗层次；五艘艇共用水花与 V 形泡沫尾浪。尾浪池标准 200 / 低画质 72，水花逐渐淡入、扩散与消散，碰撞仍使用原限频事件。艇身加入流线型蓝银面板、双推进器、脚踏、进气口和灯带；玩家与 AI 都有简化头盔驾驶员，平滑前倾/侧倾，握把固定，特技跟随视觉艇身旋转。

晴天城市加入玻璃幕墙楼群、三座高架桥、原创广告牌和岸边灯柱，桥底 18m，跳台和检查点位置不变。低画质减少水面网格与波纹层次，并隐藏部分城市细节。倒计时声音遵守首次用户交互限制；混音有压缩保护，持续源和短声音都有预算。

第一张地图为「天际环城水道」：中心半径 120 米，水道宽 44 米，沿水面箭头前进。必须依次正向穿过 CP 01–07，再跨越 START / FINISH 才完成一圈。青色亮起的门是下一检查点。初次越过起点不计圈；漏点、逆行、在门外穿越及大幅瞬移不会获得检查点计分。内外墙限制摩托位置，碰墙会减速。

HUD 显示 POS / LAP / TIME、速度、下一检查点或逆行提醒。玩家极速 180 km/h，约 2.35 秒达到 100 km/h、4.7 秒达到极速（持续加速且不碰墙）。4 位普通 AI 使用不同颜色、基础车道及 175/170/165/160 km/h 的正常速度目标。AI 提前判断跳台拥挤程度、助跑速度、对准时间及落地区域，平滑进入跳台或绕行；与玩家共用腾空、特技和氮气规则。AI 氮气使用同样的 +20% 上限及有限能量，碰撞、急转与落地危险时停止使用。排名基于已验证检查点与当前路段进度，完赛选手按完赛时间排列。

- **返回赛道**：回到最近已通过检查点之后（未通过检查点则回到发车处），保留比赛时间和进度，不额外计圈。
- **重新比赛 / 再赛一场**：清空全部成绩，重置玩家、AI 与尾浪，重新倒计时。
- **画质**：标准像素比上限 1.75，低画质上限 1。

玩家与所有 AI 使用贴合船身的水平胶囊碰撞体。追尾、侧面擦碰、迎面碰撞和 AI 之间的接触会分离船身并减速，碰撞不会增加速度；高速运动细分检测以避免穿透。AI 从碰撞后的实际位置继续前进，严重受阻时短暂偏移车道脱困，再回归原路线。已完赛 AI 在玩家结算前继续航行，避免堵住终点，已记录成绩不变。

玩家跑完三圈后立即结算并冻结比赛计时。结果包含玩家排名、用时及五位选手；此时尚未完赛的 AI 显示「未完赛」，按当时进度排序。切到后台时暂停计时和模拟，并清空输入。

## 模块结构

| 目录 | 职责 |
| --- | --- |
| `src/core` | 生命周期、场景、固定 60Hz 模拟与模块协调 |
| `src/player` | 独立驾驶模型、可替换且支持配色的摩托模型 |
| `src/config` | 玩家与普通 AI 的统一速度调节参数 |
| `src/controls` | 键盘/多指触控统一输入 |
| `src/camera` | 平滑第三人称跟随与速度 FOV |
| `src/track` | 纯赛道几何、边界、检查点穿越判断与独立 3D 展示 |
| `src/race` | 倒计时、有效进度、圈数、排名与完赛状态 |
| `src/ai` | 路线恢复、跳台选择、特技决策与有限氮气决策 |
| `src/debug` | 可关闭的跳台轨迹、状态、碰撞修正与拒绝原因诊断 |
| `src/physics` | 船身胶囊碰撞、运动子步、位置分离和限能量速度响应 |
| `src/effects` | 第一阶段轻量水面与实例化尾浪 |
| `src/environment` | 实例化城市、玻璃幕墙、桥梁与装饰质量开关 |
| `src/audio` | 可扩展的合成音效、平滑增益、音量和声音源预算 |
| `src/ui` | HUD、结果页、响应式布局与计时格式 |
| `tests` | 驾驶回归与比赛核心循环测试 |

Three.js 单独打包，业务逻辑保持小体积；水道边界、城市和箭头使用实例化，艇身静态零件按材质合并。无动态阴影、后处理或复杂流体模拟。显示位置在固定物理步进之间插值，摄像机使用同一显示姿态，减少高刷新率下的位置跳动；不叠加历史帧或运动模糊。尾浪约 1.45 秒消散，锚定水面位置，不累积船体画面。后续改进 AI 可在独立模块进行，无需改键盘、触控或摄像机。

正常速度调节入口为 `src/config/speed.ts`，面向调参使用 km/h，运行时转换为 m/s。玩家加速推力从 14 m/s² 随速度增加逐渐降至 10 m/s²（还会扣除原有水面阻力）；普通 AI 加速度为 12 m/s²。转向仍沿用原响应曲线、平滑时间与侧滑惯性，并在超过原 38 m/s 极速后保持原高速转向上限。氮气调节入口为 `src/config/phase3.ts`，默认不启用氮气时的原驾驶积分保持不变。

## 验证与限制

`npm test` 当前共 66 项，原有 57 项回归全部保留，新增水面质量、共享特效池、模型/姿态、环境净空和倒计时测试。最新结果、文件清单和实际性能测量见 [第四阶段验收](docs/phase-4-validation.md)。[跳台修复与 AI 验收](docs/ramp-ai-validation.md)与[第三阶段验收](docs/phase-3-validation.md)保留为历史记录，素材说明见 [素材与音效来源](docs/assets-license.md)。

按 F8 开关跳台诊断，也可使用 `?debugRamps=1`。面板显示艇 ID、跳台 ID、运动状态、前后物理步位置、水平/垂直速度、高度、碰撞修正距离、艇体支撑比例及起跳/拒绝原因。控制台 `[ramp]` 在重要状态改变时记录完整碰撞子步轨迹；默认关闭，历史最多保留 240 条。

当前为简单环形赛道；AI 使用环形导航和轻量的拥挤/超车判断，没有复杂超车策略，内侧路线更短会影响最终名次。船间碰撞为带高度差过滤的水平胶囊体街机响应，边界仍使用径向位置约束，没有真实刚体、翻船或破坏模拟。手机使用浏览器触摸模拟验证，真实 Android/iOS 性能还需实机验证。计时基于固定模拟步进，后台暂停，完赛时间精度为一个模拟步长。

跳跃采用纵向弹道和原水平驾驶，不是真实刚体。AI 特技仅旋转视觉船体，不影响碰撞朝向；落地后以原车道恢复速度回归路线。音效是基础合成音色。跳台边缘支撑感、碰撞后落地手感和 AI 决策频率需要实际试玩确认。没有加入商店、多地图、升级或多人联网。

## Windows 本地试玩

双击项目根目录的 `启动本地试玩.cmd`，会在后台启动本地预览并打开 `http://127.0.0.1:5174/`；重复启动会复用已有游戏服务。电脑重启后需再双击一次，地址仅访问本机，与外网连接无关。若缺少生产构建，会先执行类型检查与构建；若已修改源码，请先运行 `npm run build` 更新 `dist`。启动日志在 `.qa/local-preview.log` 和 `.qa/local-preview-error.log`。此入口不修改游戏逻辑，也不设置开机自启动。

## GitHub Pages 部署

保留相对资源路径 `base: './'`。运行 `npm run build` 后部署 `dist`；也可推送 main 并在仓库 Settings → Pages 中选择 GitHub Actions，使用已有部署工作流。尚未执行在线发布。
