# 极速水城：未来竞速

TypeScript + Three.js + Vite 原创网页水上竞速原型。当前试玩版：4.75 km 六区样条水道、两条合法捷径、三处跳台、可编辑GLB水上摩托和骨骼车手、分区未来城市及水面/空中动态混音。保留三圈比赛、4 位 AI、实体碰撞、特技和有限氮气。

最新一轮升级玩家/AI的PWC与真实比例骨骼车手，采用经核验的免费CC0基础资产进行Blender改模，加入双层水面法线、Fresnel和样板区静态反射。模型来源、许可证、7类截图与实测见 [车手、快艇与水面验收](docs/racecraft-water-validation.md)。本轮没有扩建城市或改变驾驶、碰撞和比赛规则。正常运行使用已提交GLB；仅重新生成资产需要Blender 4.5+，可设置BLENDER_PATH。来源与可编辑文件见 [资产说明](assets/racecraft/README.md)。

历史记录：**280米 Blender 城市样板区**，位于中央水道（发车后不远）。采用三种原创建筑、完整拱桥、连续水岸和免费 CC0 PBR 贴图；仅替换该段视觉，没有扩展至全地图，摩托和驾驶员保持不变。对比截图、预算与实测见 [样板区验收](docs/city-sample/validation.md)，资源逐项核验见 [来源清单](docs/city-sample/resources.md)。美术尚未达到《激流快艇2》成品水平，等待用户验收。

最新视觉修订增加城市商业/维修/交通层次与三栋独立标志建筑，修复现用41块路牌的镜像/背面问题。标准街区22.26万面、低精度8.90万面；完整同镜头截图与运行证据见 [竞速氛围验收](docs/city-sample/atmosphere-validation.md)。此前样板验收保留为历史。

样板区标准画质使用局部2048²日光阴影，在加载、质量切换或近景室内显隐集合变化时更新；低画质关闭阴影、使用10.2万面/512²贴图资源。最新修订加强日光明暗与基座遮蔽，玻璃加入视差假室内，9处水岸服务建筑加入浅层室内空间。对比截图、测试与限制见 [建筑光照与内部空间验收](docs/city-sample/interior-validation.md)。其余阶段的说明保留为历史记录。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
# 修改模型源后重新导出四个 GLB
npm run assets:build
```

手机与电脑连接同一局域网，使用终端显示的 Network 地址访问。推荐横屏，手机默认低画质；若无法访问，请检查网络和防火墙端口。

## 比赛与操作

进入页面后倒计时 3 秒，然后开始三圈竞速。W 加速、S 减速、A/D 转向，也支持方向键。空中按一次空格触发自动特技；按住 Shift 使用氮气，松开停止消耗。手机保留方向、加速与刹车，并提供特技和氮气独立按钮。正常驾驶惯性、转向和基础镜头参数保留。

赛道中部有 3 处绿色边缘跳台，速度越高，跳得越高、越远。充足腾空时间下自动选择前空翻、后空翻、水平旋转；每次跳跃只接受一次特技。完成动作并安全落地奖励 35% 氮气，晚触发或落地失误短暂减速。特技不会旋转真实碰撞体。

每场初始氮气 40%，最大 100%，每秒消耗 22%。氮气最高 216 km/h，比正常极速高 20%；带蓝色喷射和适度镜头变化，耗尽后平滑恢复正常上限。返回赛道保留现有能量，重新比赛恢复初始能量。

水花随速度、转弯、起跳、落水和碰撞变化，腾空不生成贴水尾浪。PC 水花池最多 360 个粒子，低画质最多 96 个。音效在首次用户键盘/触控操作后启动，右上角可关闭或调音量；发动机、水流、氮气、落水和碰撞声音均由 Web Audio 原创合成。

第四阶段增加多方向水纹、日光高光和水面明暗层次；五艘艇共用水花与 V 形泡沫尾浪。尾浪池标准 200 / 低画质 72，水花逐渐淡入、扩散与消散，碰撞仍使用原限频事件。艇身加入流线型蓝银面板、双推进器、脚踏、进气口和灯带；玩家与 AI 都有简化头盔驾驶员，平滑前倾/侧倾，握把固定，特技跟随视觉艇身旋转。

晴天城市加入玻璃幕墙楼群、三座高架桥、原创广告牌和岸边灯柱，桥底 18m，跳台和检查点位置不变。低画质减少水面网格与波纹层次，并隐藏部分城市细节。倒计时声音遵守首次用户交互限制；混音有压缩保护，持续源和短声音都有预算。

当前地图为「曙光都市 · 六区环线」：4,745 米闭合样条水道，包括中央发车、连续 S 弯、高架飞跃、地下水道、开放港湾和终点冲刺。主线全宽约 30–56 米，捷径宽 14/16 米。沿箭头正向依次通过 CP 01–23，再跨越 START / FINISH 完成一圈；三圈共 72 次有效门通过。两条捷径各自设有对应逻辑检查点，不能靠跳点获利。初次越过起点不计圈；漏点、逆行和大幅瞬移不会计分。岸壁约束和船身碰撞保持开启。

无氮气的浏览器自动驾驶首圈约 109 秒；实际用时随操作而变化。捷径分别节约约 100/66 米，但入口更窄。AI 按实际位置积分、预判弯道减速、提前对准跳台，并与玩家共用腾空/特技/氮气模块。此前的圆形 `Track` 仅保留为历史回归测试夹具，游戏使用 `CityTrack`。

船身通过原创截面曲线放样、曲面封口和材质合并导出 GLB；驾驶员采用曲面躯干/四肢、头盔与分层关节动画。玩家标准模型、AI 低精度模型均由 GLTFLoader 加载并共享基础资源；没有 Blender 手工雕刻、骨骼蒙皮或烘焙贴图。制作源为 `scripts/build-models.mjs`，来源及资产预算见 [模型说明](public/models/README.md)。

离水时快速平滑降低水流/破浪声，增加风声，发动机与氮气继续响应；落水冲击后恢复贴水混音。四个 AI 使用同一混音逻辑并按距离衰减，持续声源数量固定，短声音最多六个。

HUD 显示 POS / LAP / TIME、速度、下一检查点或逆行提醒。玩家极速 180 km/h，约 2.35 秒达到 100 km/h、4.7 秒达到极速（持续加速且不碰墙）。4 位普通 AI 使用不同颜色、基础车道及 175/170/165/160 km/h 的正常速度目标。AI 提前判断跳台拥挤程度、助跑速度、对准时间及落地区域，平滑进入跳台或绕行；与玩家共用腾空、特技和氮气规则。AI 氮气使用同样的 +20% 上限及有限能量，碰撞、急转与落地危险时停止使用。排名基于已验证检查点与当前路段进度，完赛选手按完赛时间排列。

- **返回赛道**：回到最近已通过检查点之后（未通过检查点则回到发车处），保留比赛时间和进度，不额外计圈。
- **重新比赛 / 再赛一场**：清空全部成绩，重置玩家、AI 与尾浪，重新倒计时。
- **画质**：标准像素比上限 1.75，低画质上限 1。

玩家与所有 AI 使用贴合船身的水平胶囊碰撞体。追尾、侧面擦碰、迎面碰撞和 AI 之间的接触会分离船身并减速，碰撞不会增加速度；高速运动细分检测以避免穿透。AI 从碰撞后的实际位置继续前进，严重受阻时短暂偏移车道脱困，再回归原路线。已完赛 AI 在玩家结算前继续航行，避免堵住终点，已记录成绩不变。

玩家跑完三圈后立即结算并冻结比赛计时。结果包含玩家排名、用时及五位选手；此时尚未完赛的 AI 显示「未完赛」，按当时进度排序。切到后台时暂停计时和模拟，并清空输入。

## 模块结构

| 目录 | 职责 |
| --- | --- |
| `src/core` | 生命周期、场景、固定 60Hz 模拟与模块协调 |
| `src/player` | 独立驾驶模型、可替换且支持配色的摩托模型 |
| `src/config` | 玩家与普通 AI 的统一速度调节参数 |
| `src/controls` | 键盘/多指触控统一输入 |
| `src/camera` | 平滑第三人称跟随与速度 FOV |
| `src/track` | 纯赛道几何、边界、检查点穿越判断与独立 3D 展示 |
| `src/race` | 倒计时、有效进度、圈数、排名与完赛状态 |
| `src/ai` | 路线恢复、跳台选择、特技决策与有限氮气决策 |
| `src/debug` | 可关闭的跳台轨迹、状态、碰撞修正与拒绝原因诊断 |
| `src/physics` | 船身胶囊碰撞、运动子步、位置分离和限能量速度响应 |
| `src/effects` | 第一阶段轻量水面与实例化尾浪 |
| `src/environment` | 实例化城市、玻璃幕墙、桥梁与装饰质量开关 |
| `src/audio` | 可扩展的合成音效、平滑增益、音量和声音源预算 |
| `src/ui` | HUD、结果页、响应式布局与计时格式 |
| `tests` | 驾驶回归与比赛核心循环测试 |

Three.js 单独打包，业务逻辑保持小体积；水道边界、城市和箭头使用实例化，艇身静态零件按材质合并。标准画质为城市样板使用局部静态2048阴影；无后处理或复杂流体模拟。显示位置在固定物理步进之间插值，摄像机使用同一显示姿态，减少高刷新率下的位置跳动；不叠加历史帧或运动模糊。尾浪约 1.45 秒消散，锚定水面位置，不累积船体画面。后续改进 AI 可在独立模块进行，无需改键盘、触控或摄像机。

正常速度调节入口为 `src/config/speed.ts`，面向调参使用 km/h，运行时转换为 m/s。玩家加速推力从 14 m/s² 随速度增加逐渐降至 10 m/s²（还会扣除原有水面阻力）；普通 AI 加速度为 12 m/s²。转向仍沿用原响应曲线、平滑时间与侧滑惯性，并在超过原 38 m/s 极速后保持原高速转向上限。氮气调节入口为 `src/config/phase3.ts`，默认不启用氮气时的原驾驶积分保持不变。

## 验证与限制

`npm test` 当前 94 项，保留原有驾驶与比赛回归，包含样板GLB材质、LOD、水道净空、路牌方向/UV、室内选择与玻璃着色器测试。最新光照与假室内截图见 [建筑光照与内部空间验收](docs/city-sample/interior-validation.md)。26种模块、189处城市布局和近中景单体细节见 [密度与单体精度验收](docs/city-sample/detail-validation.md)。[上一轮城市丰富度验收](docs/city-sample/richness-validation.md)保留137处布局时的历史记录。[上一轮城市规模验收](docs/city-sample/density-validation.md)保留88处布局时的历史对比。[质感强化验收](docs/city-sample/material-validation.md)、[竞速氛围验收](docs/city-sample/atmosphere-validation.md)、[第五阶段验收](docs/phase-5-validation.md)、[第四阶段验收](docs/phase-4-validation.md)、[跳台修复与 AI 验收](docs/ramp-ai-validation.md)与[第三阶段验收](docs/phase-3-validation.md)保留为历史记录，素材说明见 [素材与音效来源](docs/assets-license.md)。

按 F8 开关跳台诊断，也可使用 `?debugRamps=1`。面板显示艇 ID、跳台 ID、运动状态、前后物理步位置、水平/垂直速度、高度、碰撞修正距离、艇体支撑比例及起跳/拒绝原因。控制台 `[ramp]` 在重要状态改变时记录完整碰撞子步轨迹；默认关闭，历史最多保留 240 条。

AI 使用样条导航和轻量的拥挤/超车判断，没有复杂战术。船间碰撞为带高度差过滤的水平胶囊体街机响应，岸壁采用采样水道投影约束，没有真实刚体、翻船或破坏模拟。手机保留低画质入口，真实 Android/iOS 性能尚未验证。计时基于固定模拟步进，后台暂停，完赛时间精度为一个模拟步长。原项目只有当场成绩，没有跨刷新持久最佳成绩；本阶段没有补做该系统。

跳跃采用纵向弹道和原水平驾驶，不是真实刚体。AI 特技仅旋转视觉船体，不影响碰撞朝向；落地后平滑回归路线。音效仍是合成音色。城市是原创模块化程序几何，尚非专业手工美术资产。跳台边缘支撑、捷径汇合、驾驶员姿态和实际听感需人工试玩确认。没有加入商店、多地图、升级或多人联网。

## Windows 本地试玩

双击项目根目录的 `启动本地试玩.cmd`，会在后台启动本地预览并打开 `http://127.0.0.1:5174/`；重复启动会复用已有游戏服务。电脑重启后需再双击一次，地址仅访问本机，与外网连接无关。若缺少生产构建，会先执行类型检查与构建；若已修改源码，请先运行 `npm run build` 更新 `dist`。启动日志在 `.qa/local-preview.log` 和 `.qa/local-preview-error.log`。此入口不修改游戏逻辑，也不设置开机自启动。

## GitHub Pages 部署

保留相对资源路径 `base: './'`。运行 `npm run build` 后部署 `dist`；也可推送 main 并在仓库 Settings → Pages 中选择 GitHub Actions，使用已有部署工作流。尚未执行在线发布。
